# Garage Math — 6th Grade

A 36-week hands-on sixth-grade math curriculum built around car racing, welding, dirt bikes, tools, fabrication, and real-world garage math.

## Included
- 36 weekly curriculum modules
- Printable student worksheets
- Answer keys
- Hands-on garage challenges
- Supporting Khan Academy video links
- Responsive website for phones, tablets, and computers

## Website files
- `index.html` — site structure
- `styles.css` — visual design and print styles
- `app.js` — full curriculum, worksheets, answer keys, and interactions

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/(root)**, then save. GitHub will provide the public website address after Pages is enabled.
